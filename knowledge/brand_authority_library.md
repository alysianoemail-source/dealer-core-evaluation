## 分级标准

| 等级 | 标准 | L2品牌评分基准 | 示例 |
|------|------|--------------|------|
| **S级** | 全球一线品牌，市场份额 Top3，品牌价值百亿级 | 90-100 | Apple、华为、三星 |
| **A级** | 全国性头部品牌，行业 Top5，品牌知名度高 | 75-89 | 荣耀、海尔、格力、美的 |
| **B级** | 区域性中端品牌，在特定区域有较强影响力 | 55-74 | 区域性家电/手机品牌 |
| **C级** | 小众品牌/白牌/无自有品牌（纯分销） | <55 | OEM/ODM分销商、贴牌 |

## 分级依据维度

```
品牌等级 = f(市场份额, 品牌价值, 授权状态, 舆情口碑)

市场份额:
  S ≥ 15% | A 5-15% | B 1-5% | C < 1%
品牌授权:
  S/A = 官方授权书 + 授权期限 ≥ 1年
  B = 授权书可查，但非一级授权
  C = 无授权 / 授权过期 / 贴牌
```

## 特殊规则

| 场景 | 处理 |
|------|------|
| 无品牌授权 | L2 品牌维度 ≤ 30 分，标记"无正规授权" |
| 假冒品牌 | 一票否决，直接不通过 |
| 品牌授权即将到期（<3个月） | 扣 10 分，标注"授权即将到期，需续期" |
| 多品牌经销 | 取最高品牌等级评分，但标注品牌组合 |
