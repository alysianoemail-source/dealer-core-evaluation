## 分类说明

| 分类 | 含义 | L1校验结论 |
|------|------|-----------|
| **鼓励类** | 银行优先支持行业 | L1 通过 → 进入 L2 打分 |
| **限制类** | 审慎准入，需附加条件 | L1 待复核 → 人工确认 |
| **禁止类** | 不得准入 | L1 不通过 → 直接拦截 |

---

## 鼓励类

| 行业 | 说明 | 判定依据 |
|------|------|---------|
| 消费电子 | 智能手机、可穿戴设备等 | 行业景气上行，需求稳定 |
| 智能家电 | 白电、小家电、智能家居 | 成熟行业，品牌集中度高 |
| 新能源设备 | 光伏、储能、风电设备 | 国家扶持，增长期 |
| 医疗器械 | 诊断设备、耗材 | 刚需市场，政策支持国产替代 |
| 食品饮料 | 品牌食品、饮料经销 | 快消品，周转快 |

## 限制类

| 行业 | 说明 | 限制条件 |
|------|------|---------|
| 储能设备 | 产能过剩风险上升 | 需额外提供产能利用率证明 |
| 房地产建材 | 地产下行周期 | 仅接受头部品牌经销商 |
| 传统燃油车 | 新能源替代加速 | 仅限头部品牌 + 转型计划 |
| 纺织服装 | 竞争激烈，利润薄 | 需品牌授权 + 年营收≥3000万 |

## 禁止类

| 行业 | 说明 |
|------|------|
| 高污染高耗能 | 钢铁、水泥、造纸（落后产能） |
| 淘汰类行业 | 国家发改委《产业结构调整指导目录》淘汰类 |
| 虚拟货币/区块链（纯金融） | 政策禁止 |
| 赌博/成人/非法品类 | 违法 |
| 两高一剩（未转型） | 钢铁、电解铝、水泥、平板玻璃 |
