> last_updated: 2026-07-23
> maintainer: [待指定]

---

## 概述

红线规则是一票否决级判定。**任何一条红线触发，无论其他维度评分多高，综合评级锁定为 D（不通过）。**

触发红线的企业必须：
1. 评级直接标注"一票否决：[红线名称]"
2. 在结果清单中红色高亮
3. 审计台账标记"红线案件，永久保留"

---

## 红线清单

### R001：失信被执行人

- **检查方式**：查询中国执行信息公开网 / 启信宝司法信息
- **触发条件**：企业或法定代表人被列为失信被执行人
- **后果**：一票否决

### R002：重大税收违法失信

- **检查方式**：查询税务部门公布的重大税收违法案件信息
- **触发条件**：企业被列入重大税收违法失信主体名单
- **后果**：一票否决。维度三（核企自身信用）直接归零。
- **示例**：远辰精密化工 × 鑫达供应链（d1=87，因 R002 触发 → d3=0 → 评级 D）

### R003：经营异常未移出

- **检查方式**：查询国家企业信用信息公示系统
- **触发条件**：列入经营异常名录超过 3 年未移出，或列入严重违法失信企业名单
- **后果**：一票否决

### R004：重大行政处罚（环保/安全/金融）

- **检查方式**：查询行政处罚记录
- **触发条件**：近 2 年内有环保/安全生产/金融领域重大行政处罚（罚款 > 50 万或责令停产停业）
- **后果**：一票否决。轻微行政处罚（罚款 < 10 万）→ 非一票否决，扣分处理

### R005：假冒伪劣/侵权

- **检查方式**：品牌授权核查 + 工商处罚记录
- **触发条件**：经核实存在假冒品牌、销售假冒伪劣商品、商标侵权等行为
- **后果**：一票否决

### R006：非法经营/违禁品类

- **检查方式**：经营范围核查
- **触发条件**：经营法律禁止的品类（赌博、成人、违禁药品等）
- **后果**：一票否决

## 红线触发处理流程

```
触发红线 ──→ 停止该条剩余评分 ──→ 输出已完成部分
        │                        │
        │  维度一/二若已算完      │  保留在报告中供参考
        │  则保留                │  （但评级锁定 D）
        │                        │
        └──→ 标记"一票否决：[红线名称]"
        └──→ 结果红色高亮
        └──→ 审计台账标记"红线案件，永久保留"
        └──→ 不允许批量上报
```
