# 输入文件格式说明

## 分行上报名单（CSV）

标准格式（UTF-8 with BOM）：

```csv
核心企业名称,经销商名称,统一社会信用代码(核企),统一社会信用代码(经销商),主营产品,所属行业
华曜智能终端有限公司,北辰渠道科技有限公司,91110108MA01XXXXX,91110105MA01YYYYY,智能手机,消费电子
```

字段说明：

| 字段 | 必填 | 说明 |
|------|------|------|
| 核心企业名称 | ✅ | 全称，与工商注册名一致 |
| 经销商名称 | ✅ | 全称，与工商注册名一致 |
| 统一社会信用代码(核企) | ❌ | 18位，有助于精确匹配 |
| 统一社会信用代码(经销商) | ❌ | 18位，有助于精确匹配 |
| 主营产品 | ❌ | 辅助L1校验 |
| 所属行业 | ❌ | 辅助L1校验 |

## 注意事项

- 编码必须为 UTF-8（Excel 导出建议带 BOM）
- 每行一对"核心企业-经销商"，不可一对多
- 文件名建议：`{批次描述}_{日期}.csv`
