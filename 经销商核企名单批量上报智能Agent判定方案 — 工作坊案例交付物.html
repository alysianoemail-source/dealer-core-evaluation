L1 / L2 分层双维度判定框架
L1 快速过滤 · L2 精细打分
L1 层 基础准入初筛 — 四大核心维度（批量前置拦截）
  1. 经营主体匹配度：核对营业执照主体名称、统一社会信用代码、注册地址、法人；校验是否独立法人企业；排除个体工商户、分公司、挂靠空壳、已注销 / 吊销主体。
  2. 主营商品匹配度：提取经营范围与对外主打产品，匹配本行准入品类；剔除主营非合作品类、无实体产品、仅中介倒卖无货源企业。
  1. 所属行业匹配度：对照白名单行业目录，区分鼓励 / 限制 / 禁止类；直接拦截禁止类，限制类进入 L2 复核。
  2. 营销经销体系基础条件：核查线下门店、分销渠道、销售团队、下游客户资源；无稳定经销网络、仅零散散户直接不合格。
L1 输出：① 直接合格 → 进入 L2 深度校验  |  ② 直接不合格 → 标注拦截原因，无需上报  |  ③ 待复核 → 行业 / 渠道模糊，流转 L2 人工 + Agent 复合核查
L2 层 深度尽调合规判定 — 四维精细化打分（L1 通过企业）
  1. 经营主体资质风险（负面拦截）：工商信息（经营状态、实缴资本、年限、股权变更、失信、异常）；司法信息（失信被执行人、限高、大额纠纷、担保诉讼、税务处罚）；舆情信息（质量曝光、虚假宣传、卷款跑路、劳资纠纷）；负面清单（监管黑名单、金融失信、渠道违规台账）。1 项重大负面直接不合格。
  2. 主营商品与品牌价值：品牌资质（正规注册商标、官方经销授权书、授权期限）；品牌分层（一线头部高加分 / 区域中端中等 / 小众杂牌扣分）；商品合规（质检报告、3C 认证、行业准入资质）。
  1. 所属行业发展前景：行业生命周期（朝阳增长支持 / 成熟稳定中性 / 衰退淘汰限制）；行业政策（国家扶持 / 监管收紧，高耗能高污染产能过剩限制）；行业竞争格局（赛道容量、需求稳定性）。
  2. 成熟经销商经销体系：渠道布局（门店数量、覆盖区域、线上电商团购）；上下游体系（上游稳定供货品牌方、下游固定终端客户、长期协议）；运营团队（专职销售仓储售后、标准化进销存对账返利）；历史经销规模（近 1-3 年营收、拿货量、年度分销流水）。
L2 输出：四维综合评分 → A 级合格（可直接上报）/ B 级风险（暂缓上报，补充材料复核）/ C 级不合格（标注风险点不予上报）

5 条脱敏评测样例
覆盖五种典型场景 · 每条含期望输出与红线
样例类型 脱敏输入 期望输出 不能犯的错
✅ 正常合格 深圳 XX 家电商贸有限公司，独立法人，注册资本 500 万实缴，主营美的 / 格力家电，有品牌授权书（有效期 2027 年），全国 20 家门店，年流水 8000 万，无司法负面。 L1 通过 → L2 评级 A 级 → 判定合格，允许上报。输出完整判定报告：主体合规 + 品牌授权齐全 + 行业鼓励类 + 经销体系成熟 + 无负面。 不能凭空添加未验证的加分项；不能遗漏品牌授权有效期核验。
❌ 主体不符 东莞 XX 个体经销部，营业执照类型为个体工商户，无统一社会信用代码对应的企业资质，主营五金杂货，无门店仅赶集摆摊。 L1 直接不通过，标注拦截原因：经营主体为个体工商户，非独立法人企业。无需进入 L2。输出拦截报告。 不能因"看着像正经生意"就放行进入 L2；主体类型是硬门槛。
❌ 禁止行业 佛山 XX 化工贸易分公司，主营危险化学品经营，所属行业在本行禁止类目录中，且为分公司非独立法人。 L1 直接不通过，标注拦截原因：禁止类行业 + 分公司主体。双重拦截。输出拦截报告并引用禁止类目录版本号。 不能将禁止类行业降级为限制类处理；必须引用规则版本号可追溯。
❌ 司法失信 惠州 XX 建材贸易公司，独立法人经营 5 年，L1 通过（主体 / 商品 / 行业 / 渠道均达标），L2 调取司法数据发现法人被列为失信被执行人，存在 2 起大额合同纠纷。 L1 通过 → L2 判定不合格，标注重大负面：失信被执行人 + 大额诉讼。输出风险证据（法院文书编号 + 失信公告链接）。 不能漏查司法失信记录；不能将重大负面降级为"轻微风险"待复核。
⚠️ 待复核 中山 XX 食品经销有限公司，主体合规，食品行业鼓励类，品牌为区域中端、授权书有效期仅剩 2 个月，8 家门店但近 1 年流水下滑 30%，有 1 起已结案小额纠纷。 L1 通过 → L2 评级 B 级 → 暂缓上报，待复核。列出存疑点：①品牌授权即将到期需续签确认 ②流水下滑需补充近半年明细。输出补件指引清单。 不能直接判定合格忽略授权到期风险；不能直接判定不合格未给企业补充材料机会。

2 分钟路演稿
六句话讲清楚 · 不铺背景直接讲产品
① 场景
我们做的是分行零售信贷风险管理部核企专员的智能体。每周要批量上报 20-80 家经销商核企名单，现在专员逐家查工商、查司法、查舆情，一批 80 家要花 2-3 天，上报后退回率 25%。
② 价值
Agent 分两层判定：L1 批量初筛四维准入，L2 深度尽调四维打分。80 家从 2-3 天压缩到 2 小时，退回率从 25% 降到 8% 以下，司法失信零漏查。
③ 输入输出
用户给一份 Excel 名单（企业名称、信用代码、主营产品、行业、渠道简介），Agent 交付三张分类表——合格可直接上报、不合格标注拦截原因、待复核列出补件清单——每条附完整判定依据和风险证据。
④ 记忆
必须记规则版本号和已确认的判定结论（可追溯审计）；临时记本轮处理上下文，24h 后自动清；坚决不记法人身份证、银行账户、未脱敏司法文书——输入层做敏感字段拦截替换。
⑤ 边界
AI 做初筛、打分、证据归档、报告草稿；待复核企业的最终结论必须人工签字；不合格企业可申诉由人工复核；AI 不替代审批人、不自动放行、不对外承诺授信。
⑥ 验收
5 条样例覆盖正常合格、个体拦截、禁止行业、司法失信、待复核。L1 准确率 ≥ 95%、负面清单命中率 100%、不能漏查司法失信、不能误判禁止行业为合格。下周可找一批真实脱敏名单试跑。

下一步试点建议
先小范围验证 · 再逐步推广

第一周：选定 1 家分行 · 跑通 3 批样例

选一家经销商上报量大的分行（如深圳分行），用历史已上报名单做回溯测试，对比 Agent 判定与人工历史结论，验证 L1 准确率和负面命中率。目标：跑通完整 Loop，确认数据接口稳定。

第二至四周：双轨并行 · Agent 初筛 + 人工复核

Agent 生成的判定结果不直接上报，先由核企专员人工复核对比，积累判定偏差案例。每周复盘，调优 L1 规则阈值和 L2 打分权重。目标：准确率达标（L1 ≥ 95%），退回率下降可量化。

第二个月：扩大到 3-5 家分行 · 上线合格名单自动上报

合格名单（A 级）经 Agent 判定后可直接进入上报流程，待复核（B 级）和不合格仍需人工确认。同步上线审计日志和规则版本管理。目标：单批处理时长稳定在 2 小时内，退回率 ≤ 8%。

第三个月起：全行推广 · 评测常态化

全行推广，评测集每月更新，规则版本季度迭代。建立"Agent 判定准确率月报"机制，异常案例自动进入评测集，形成持续优化闭环。
